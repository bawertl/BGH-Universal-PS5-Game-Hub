# GitHub-Workflow-Prüfung, 14. Oktober 2026

Ausgangsbasis: PS5 Universal Game Launcher V0.5; sämtliche Programmmodule der V0.5 übernommen. Schwerpunkt ausschließlich PS5-Toolchain, Paketierung und automatisierte Artefaktvalidierung.

## Behobene konkrete Fehler

1. **Falsches Repackaging:** V0.5 nutzte `zip -r` über den Titelordner, obwohl das gepinnte UI-Kit selbst `dist/<TITLE_ID>.zip` erzeugt und mit `tools/zip-open-modes.py` die für PS5 nötigen `0777`-Rechte herstellt. Das neue Skript kopiert die bereits erzeugte ZIP bytegleich und überprüft die Modi.
2. **Kein eindeutiger Build-Artefakt-Test:** Neu ist `tooling/verify_ps5_package.py` mit Fail-Closed-Prüfungen (Dateisignaturen, ZIP-CRC, ZIP-Pfade, Modi, Identitätsmetadaten, Pflichtdateien). Keine Linux-ELF wird akzeptiert. Diese Prüfung allein ersetzt **nicht** die upstream `self --inspect`-Schritte und keinen Hardwaretest.
3. **Unbeabsichtigter Wrapper-ZIP-Download:** Workflow verwendet `actions/upload-artifact@v7` mit `archive: false`, damit die PS5-ZIP als eigenständige Datei erhalten bleibt.
4. **Kein freier CI-Start ohne Quellcodeänderung:** Der Workflow reagiert jetzt auf jeden Push und auf `workflow_dispatch` und benötigt keine Workflow-Inputs.
5. **Ungeprüfter UI-Kit-Checkout:** CI benutzt stets Git und prüft den festgelegten Commit. Ein Kit-Verzeichnis ohne `.git` wird normalerweise abgelehnt; eine ausdrückliche lokale Simulationsoption existiert nur für Mock-Tests.

## Ausgeführte Prüfungen

- `python -m pytest -q tests`: 32 Tests erfolgreich.
- `bash tooling/test_native_gui_syntax.sh`: erfolgreich gegen Host-Shim-Headers; **keine** PS5-Toolchain.
- `bash -n tooling/build_native_ps5.sh`: erfolgreich.
- GitHub-Workflow-YAML lokal geparst; erwartete Events: `push`, `workflow_dispatch`.
- Kompletter Paketierungsablauf mit *synthetischem* UI-Kit und absichtlich unechten SELF/FSELF-Fixtures simuliert: die vom Mock erzeugte ZIP wurde bytegleich übernommen, SHA-256 bestätigt. Ein Mock ist **kein echter PS5-Build**; die Testdateien werden nicht ausgeliefert.
- Diese Umgebung kann `github.com` nicht per DNS auflösen (`curl: (6) Could not resolve host`); kein verifizierbarer echter PS5-Build möglich.
- Verfügbare GitHub-Integration: öffentliche Repositories lesen; aktuell **kein beschreibbares Repository** für dieses Projekt und **keine freigegebene Workflow-Dispatch-Aktion**.

## Technisch weiterhin offen

Ein echter Compiler- und Linklauf gegen das gepinnte UI-Kit muss auf GitHub Actions erfolgen. Erst dessen Resultate erlauben Aussagen zu PS5-Buildfehlern. Firmware 13.60, benötigte Datei-Rechte zur Laufzeit, USB-Zugriff, App-Registrierung und Emulator-Launch-Integration können nur auf echter PS5 bestätigt werden.

Die private PS5-Konfiguration wurde nicht angetastet.
