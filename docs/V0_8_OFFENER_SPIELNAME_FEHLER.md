# Offener Fehler: Fragezeichen im angezeigten Spielnamen

Beispiel: Marvel’s Wolverine erscheint mit Fragezeichen statt korrekter Beschriftung.

Nicht Bestandteil von BGH V0.8. Die Titel- und Unicode-/Schriftbehandlung ist ausdrücklich unverändert; Untersuchung und Behebung sind für eine spätere Version vorgesehen.
