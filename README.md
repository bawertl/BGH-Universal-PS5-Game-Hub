## ✨ Features

- **PS5 and PS4 game library**
- **PlayStation 2 integration with PS5SX2**
- **Nintendo Switch integration with ProsperoEden and ForgeNX**
- **Xbox 360 integration with PS5X360**
- Game cover artwork and console categories
- Favorites and recently played games
- Customizable backgrounds and logos
- Game folder management and library scanning
- Controller-friendly navigation
- German and English interface
- Emulator-specific launch profiles

**BGH is a launcher, not an emulator.**

External emulators must be installed separately.

## 🔧 Requirements

The tested BGH setup uses:

| Component | Purpose |
|---|---|
| **etaHEN** | Jailbreak and homebrew environment |
| **ShadowMountPlus** | Supported PS5 dump and USB functionality |
| **Launcher ELF** | Game and emulator launch requests |
| **ftpsrv** | FTP-based library functionality |
| **elfldr** | Loading ELF payloads |
| **Emulator helpers** | Additional PS2 launch functionality |

### Important Ports

- **10199** – Launcher / Forwarder
- **2121** – FTP server
- **9021** – ELF loader
- **10101** – ShadowMountPlus storage API

**IMPORTANT: BGH does not automatically activate these external services.**

Start the required services before using the corresponding game-launch functions.

See the latest release for the complete installation and startup instructions.
